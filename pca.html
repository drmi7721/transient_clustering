Overview

The core of principal component analysis (PCA) is reducing the dimensions of a dataset such that it maintains most of the structure. Dimensionality reduction can be useful when dealing with real datasets that can contain hundreds of features and observations, or even more! In particular, it is often the case that features are correlated with each other, which ultimately provides redundant information. Additionally, it is impossible to plot hundreds of features at the same time, so plotting the most important ones becomes much simpler when the dimensionality of the dataset is reduced. PCA decomposes the data into a new basis of "principal components", which describe the variance of the data. In particular, principal component #1 describes the largest component of variance in the data, and the other consecutive principal components describe successively smaller components of the variance. The variance of the data is captured by the eigenvalues of the covariance matrix, implying that the eigenvectors represent the principal components. Therefore, using the covariance matrix, PCA becomes a simple eigenvalue problem!

Data Prep

Since PCA will ultimately reduce the dimensionality of the data by capturing the largest components of the variance, using all of the transient temporal data will be sufficient for categorizing the transient rise and decay times. In the context of astrophysical transient detections, PCA may be able to identify different types of transients based on their typical variability by using only the largest components of variance in the data rather than combining all of the original temporal data. In the literature, scientists already know about several different transient types based on the signatures that we detect, some of which are described in the Introduction tab. The goal of PCA here is to see whether or not the transient rise and decay times can be more adequately categorized using lower-dimensional data.
