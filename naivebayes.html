Overview

Naive Bayes (NB) is a supervised machine learning method that incorporates Bayes' theorem to predict the classes occupied by observations in a dataset. Note that this requires labeled data, corresponding to the classes in this case. NB trains data by analyzing the features within each class to predict what those features look like, and then estimates a probability distribution. Bayes theorem uses the prior and likelihood, which describe the fraction of training rows that have a specific label (y=c) and the behavior of the features that have class y=c, respectively. The "naive" part comes in by assuming conditional independence, meaning that observations within a class are independent of each other. This ultimately allows for the likelihood to be split into the product of individual observation probabilities. There are several different types of NB classifiers, including Gaussian NB, Multinomial NB, and Bernoulli NB. Gaussian NB is used for continuous features while Multinomial NB is used for events/counts (or discrete features). Finally, Bernoulli NB is used for binary features specifically. In the case of this project, Multinomial NB will provide the best classifier for transient rise/decay times.

Data Prep

Since NB will predict labels of observations within the dataset, labeled numeric data is required. In the context of astrophysical transient detections, one useful label that is presented in the data is the photometric band of each observation. These bands (g, r, i) describe the wavelength ranges that each transient detection was observed in. In particular, these correspond to 400-550nm, 550-700nm, and 700-850nm, respectively. These are measured using transmission curves, which ultimately come from optical inference filters built into the instrument. All of these wavelength ranges are found in the optical/visible range of the electromagnetic spectrum, with a small fraction occupying the near-infrared range. The goal of training a NB classifier here is to see whether or not the photometric bands of transient detections can be predicted based on transient rise/decay times. To obtain more sky coverage than before, 10 randomly-selected partitions will be used to train the NB classifier, rather than the first 10 partitions of data which occupy a narrow region on the sky. This data is a result of the data cleaning that was described in the DataPrep_EDA tab. The full 10 partition dataset contains 2,634,436 rows. Finally, in order to construct a NB classifier, the data need to be split into testing and training datasets. This was accomplished by allocating 20% of the dataset to testing data, and the other 80% to training data. The split was chosen randomly, but can be reproduced using a random_state identifier. Finally, the split attempts to keep roughly the same proportions of each label in both datasets.

Results

Figure 5 shows a bar plot comparing the number of original observations per photometric band (blue) and the number of predicted observations per photometric band (orange). From this, is is clear that the NB classifier was able to correctly capture the relative numbers of observations per photometric band (e.g. r-band observations > g-band observations > i-band observations). On the other hand, the classifier overpredicts the number of r-band observations, and underpredicts the number of g-band and i-band observations. The accuracy of the NB classifier was 0.51, meaning that it was equally likely for the classifier to correctly predict the photometric band and incorrectly predict the photometric band based only on the transient rise and decay times. Figure 6 shows the corresponding confusion matrix for the NB classifier. This matrix shows the number of observation for each pair (actual, predicted) observation. The diagonals correspond to the cases where the actual and predicted observations were equivalent, while the off-diagonals correspond to cases where the prediction differed from the actual observation. Since the diagonals and off-diagonals in each column of the matrix each have the same order of magnitude, this confirms that the predicted photometric bands can be correct or incorrect with roughly equal probability.

Conclusions

Using Figures 5 and 6 above, it is clear that the NB classifier could not accurately predict the photometric band of transient events based only on transient rise and decay times. An accuracy of 0.51 means that the classifier was almost equally split between correct and incorrect predictions. The classifier did correctly predict that most of the observations are found in the r-band, then the g-band, and the finally the i-band. In conclusion, this supervised machine learning method cannot tell us whether or not transient photometric bands can be predicted based on their rise and decay times.
